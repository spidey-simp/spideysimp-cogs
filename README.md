# spideysimp-cogs

A collection of cogs for Red-DiscordBot created and maintained by spidey simp.

## Installation

To add this repository to Red, use:

`[p]repo add spideysimp-cogs https://github.com/spidey-simp/spideysimp-cogs`

To install a cog from this repository, use:

`[p]cog install spideysimp-cogs <cogname>`

Then load the cog with:

`[p]load <cogname>`

Replace `[p]` with your bot's command prefix.

## Additional Setup

Some cogs may require additional setup, permissions, dependencies, or configuration. Check the cog's installation message and help documentation for any cog-specific instructions.
